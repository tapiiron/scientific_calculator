# Implementation documentation

## Program structure

App - Provides simple interface for the user to interact with the program.
ShuntingYardTool - Provides the actual shunting yard algorithm.
ReversePolishNotationCalculator - Provides calculations based on reverse polish notation from Shunting Yard.

## Achieved time and efficiency goals

When doing load testing shunting yard algorithm was able to achieve wikipedia O(n) time complexity. Testing was done by
changing the number of test operations by hand.

## Future improvements

For the future improvements this project could be extended to include graphical or web interface.
